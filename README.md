# 🔐 Cyber Shield AI

**Cyber Shield AI** is an intelligent cybersecurity platform designed to help users identify, understand, and prevent online threats through an interactive and user-friendly interface.

---

## 🚀 Features

* 🛡️ **Threat Library**
  A structured collection of common cyber threats such as phishing, fraud, scam calls, and malware.

* 🤖 **AI Chatbot**
  Provides real-time responses and guidance to user queries related to cybersecurity.

* 📚 **User Awareness**
  Educates users about digital safety and best practices to stay secure online.

* 🌐 **User-Friendly Interface**
  Simple and clean design for easy navigation and accessibility.

---

## 💡 Project Objective

The main goal of Cyber Shield AI is to improve cybersecurity awareness among users by providing instant information and guidance about potential threats in a simple and understandable way.
